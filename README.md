**Link Shortener** — Создавайте короткие URL, отслеживайте каждый клик (IP, дата/время), управляйте ссылками через элегантную панель управления.

---

## ✨ Возможности

- ⚡ **Мгновенное сокращение ссылок** с генерацией уникального 6-символьного кода
- 📊 **Детальная статистика переходов** — IP-адрес, точное время каждого клика
- 🎨 **Современная админ-панель** на FilamentPHP v3 с тёмной темой
- 🔐 **Полная аутентификация** — регистрация, вход, восстановление пароля
- 👤 **Личный кабинет** — каждый пользователь видит только свои ссылки и статистику
- 🎯 **Сервис-ориентированная архитектура** — чистый код, разделение ответственности
- 🌐 **Публичный лендинг** с красивым градиентным дизайном
- 📋 **Копирование ссылки в один клик** прямо из таблицы

**Link Shortener** — система для сокращения ссылок с аналитикой переходов.  
Позволяет зарегистрированным пользователям создавать короткие URL, отслеживать клики и управлять своими ссылками.

🔗 **Демо:** [Деплой на Render](https://linkshortener-ldh8.onrender.com/)

---

## 📋 Требования

| Компонент | Версия |
|-----------|--------|
| PHP | 8.1+ (рекомендуется 8.3) |
| Laravel | 11.x |
| SQLite | 3.x (локально) / PostgreSQL (продакшен) |
| Node.js | 18+ |
| npm | 9+ |
| Composer | 2.0+ |
| Git | 2.0+ |
| Make | 3.81+ |
| ОС | Linux/macOS/WSL2 |

---

## 🚀 Установка и запуск

```shell
git clone git@github.com:StanislavSol/linkShortener.git
cd linkShortener
make install
make start
```
